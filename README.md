# Демо-сайт груминг-салона ЛАПКИ (шаблон для показа клиентам)

Копия ветеринарного демо (`../../vet-demo/сайт`) с другим контентом и медиа.
Видео 4 сцен и картинки мозаики сгенерированы: `../gen/gen_media.py` (Veo 3.1 Lite + Gemini 3.1 Flash Image, Vertex AI).

Салон вымышленный: название, адрес, телефон, цены - ориентир для презентации.
Два языка: RU и KZ, переключатель в шапке.

## Запуск

```
npm install        - один раз
npm run dev        - локально, http://localhost:5173
npm run build      - собрать в dist/ (это и заливаем)
```

## Что менять под реального клиента

Всё в одном файле `src/content.ts`: название и логотип, телефон, адрес, часы,
мессенджеры, тексты 4 сцен (`heroScenes`), три бара первого экрана, рукописные
заметки (`hero.note`, `gallery.note`), грумеры, прайс, 8 страниц услуг (`pages`),
тексты формы записи. Обе версии (ru, kz) рядом. Цены по размерам собак: `bySize(...)`.

Фото и видео:
- `public/scroll/*.jpg` и `public/scroll/vid/*.mp4` - сцены (vanna, sushka, strizhka, result; копии `-m` для телефона)
- `public/img/*.webp` - картинки мозаики (hero, section2, s3bg, s3img1, s3img2)

Лапка логотипа - SVG в `App.tsx` (`PawIcon`), цвет #DB7B75. Рукописный шрифт Caveat.

Форма записи сейчас только показывает «Спасибо». Для живого сайта подключить
Google Sheets + Apps Script по сниппету из проекта CRM.
